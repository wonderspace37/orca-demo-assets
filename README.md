# ORCA demo assets

Web-resolution 3D assets for the ORCA fixed-wing landing-page demos:
- `orca.glb` — meshopt-compressed airframe (30 named parts)
- `parts.manifest.json` — per-part material/group metadata
- `studio.hdr` — CC0 studio HDRI (Poly Haven, brown_photostudio)

Served to the demo sites via jsDelivr CDN.
